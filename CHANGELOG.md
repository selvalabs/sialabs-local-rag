## [0.3.1] - 2026-08-24

- Hardened hybrid dense + SQLite FTS5 retrieval and weighted RRF behavior.
- Preserved structured source citations across document formats and locators.
- Added collection-scoped incremental scanning and calibrated relevance gating.
- Expanded deterministic dense/hybrid retrieval evaluation and recorded EmbeddingGemma threshold evidence.
- Added retrieval-scale benchmark measurements with machine-specific scope.
- Added generated OpenAPI contracts and drift gates.
- Added frontend Vitest coverage and an integrated React → FastAPI → SQLite → retrieval Playwright E2E.
- Hardened Docker non-root and loopback boundaries, plus Pester 5 compatibility.
- Synchronized documentation and showcase/release evidence.

## [0.3.0] - 2026-06-22

- Windows local-app MVP and reproducible local RAG demo flow.
- Structured ingestion metadata for PDF and Office sources.
- Hybrid retrieval, collections and local runtime profiles.

Development history before this public showcase line remains in the private engineering repository. This public repository begins from the curated v0.3.1 showcase release.
